# Fonts

Self-hosted copies of the woff2 files Google Fonts serves (latin and latin-ext subsets), declared in the "Fonts" block at the top of `styles/styles.css`. The number in each filename is Google's version (`/s/<family>/v32/...`); when updating a font, download the new files under a new filename, because `customHttp.yml` tells browsers to cache them for a year without re-checking.
