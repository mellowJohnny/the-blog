Autobus Messaging Platform — User Guide

Sending a Message

Type your message in the text box. The message will always start with the default template "Autobus Cycling Club:" — just add your ride details after it.

As you type, the stats bar below the text box shows:

  • Characters — the total length of your message
  • Encoding — GSM‑7 is the standard format and fits more characters per SMS. Unicode is used automatically if your message contains special characters like curly quotes or em dashes.
  • Segments — SMS messages over 160 characters (GSM‑7) or 70 characters (Unicode) are split into multiple segments. Each segment is billed separately by Twilio, so shorter messages are more economical.

GSM‑Safe Mode

Check the GSM‑Safe Mode box to automatically replace smart punctuation — curly quotes, em dashes, ellipsis characters — with their plain equivalents. This keeps your message in the more efficient GSM‑7 format and avoids unexpected encoding issues on some handsets.

Test Mode

Check the Test Mode box before sending to deliver the message only to subscribers flagged as test users. Use this to verify your message looks correct before sending it to the full list. When Test Mode is unchecked, the message goes to all active subscribers.

Sending

Click the Send button when your message is ready. If you are in Live Mode (Test Mode unchecked), you will be asked to confirm before anything is sent. The results panel on the right will show the delivery status for each recipient, along with a summary of successful and failed sends.

Bulk Import Subscribers

Click bulk import... in the navigation to load a new subscriber list. The file must be a pre-processed JSON file in the correct format — this is prepared separately once a year from the club sign-up data.

Once you select or drop a file, the number of records is shown for review. Clicking Upload will permanently delete all existing subscribers and replace them with the new list. You will be asked to confirm before anything is deleted. A summary showing how many records were removed and how many were imported is displayed on completion.

A Note on Segments & Cost

Each SMS segment sent via Twilio incurs a small cost. Keeping messages concise and using GSM‑Safe Mode where possible helps keep the number of segments — and therefore cost — to a minimum.

Add Subscriber

Enter the subscriber's name and mobile number. The number will be automatically converted to E.164 format. Duplicate phone numbers will be rejected.
