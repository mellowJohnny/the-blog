Broken Image Check

Loads every image the live public site references - blog post images, card set header/footer images, and anything embedded in a review's body text - and checks whether each one actually loads. Only covers published/live content, not staged drafts. Takes a minute or two.

Checklist Integrity Check

Every uploaded checklist is supposed to link back to exactly one card set review by an exact setName match. This checks every uploaded checklist at once and flags any that don't have a matching review - e.g. a typo'd filename at upload time.
