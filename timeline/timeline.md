### The Junk Wax Era

#### 1984-85 O-Pee-Chee & Topps Sets
- The beginning of the Junk Wax era
- OPC: 396 bilingual cards (Canada); Topps: 165 English cards (US)
- OPC production estimated at roughly 6 million packs, based on a contest run that year
- Notable rookies: Steve Yzerman, Doug Gilmour, Chris Chelios

#### 1985-86 O-Pee-Chee & Topps Sets
- The Mario Lemieux RC set
- OPC down to 264 bilingual cards; Topps 165 cards plus a sticker in each pack
- Notable OPC rookies: Lemieux, Al MacInnis, Kirk Muller

#### 1986-87 O-Pee-Chee & Topps Sets
- The Patrick Roy RC set
- OPC steady at 264 cards; Topps up slightly to 198 cards plus a sticker
- Notable OPC rookies: Roy, Petr Klima, Wendel Clark

#### 1987-88 O-Pee-Chee & Topps Sets
- OPC stayed at 264 cards; Topps continued with 198 cards and one sticker per pack
- Notable OPC RCs: Adam Oates, Luc Robitaille, Stephane Richer, Esa Tikkanen, Rick Tocchet
- OPC released its first "Minis" set (42 cards)

#### 1988-89 O-Pee-Chee & Topps Sets
- The Brett Hull RC set
- OPC continued at 264 cards, Minis set; Topps with 198
- Rack packs returned to mass-market retailers: 42-card sealed cello packs including a "Mini" card
- Wayne Gretzky traded to Los Angeles over the summer, fueling interest in hockey south of the border

#### 1989-90 The End of the Topps / OPC Monopoly
- Last year O-Pee-Chee and Topps held exclusive rights to produce hockey cards in Canada and the US
- OPC set increased to 330 bilingual cards; standout RCs include Joe Sakic and Brian Leetch
- Topps’ 198 card set was rumoured to have a lower print run than OPC (unverifiable urban legend)
- No Minis set
- Upper Deck releases their first Baseball set 
    - Premium card stock, anti-counterfeit holograms, and foil packs to stop tampering
    - Even at twice the price of Topps, Fleer & Donruss they sold out in days


#### 1990-91 Upper Deck Arrives
- Pro Set, Pinnacle, and Upper Deck get NHL licenses: hobby explodes from two sets to nine
- Companies allowed two sets each: Some opt for French / English, some produce "regular" & "premium" sets
- Set sizes explode:
  - Pro Set's enormous 705-card set, with countless errors
  - Upper Deck's 550-card sets (English & French) released across two Series
    - “High” Series Factory sets
    - First Upper Deck Young Guns cards
    - French set frenzy: Canada-only edition reportedly had lower production
  - O-Pee-Chee's 528-card "main" set, and "limited" 132-card Premier set
    - Premier sets the hobby world on fire, further stoking speculation
    - Also available as a Factory set 
  - Topps: 396-card main set and "premium" 264 card Bowman set, still with gum!
  - Score's (Pinnacle) 440 cards sets; one American, one Canadian, also in Factory Sets
    - Eric Lindros mania as Score has the only official RC
- In total 4,005 base cards were available to collect
- Over-production:
  - Upper Deck “High” Series packs contained a mix of Low and High Series cards  
  - Upper Deck and Pro Set go back to the presses for multiple print runs as demand continues  
- Factors driving speculation:
  - First Beckett hockey price guide: Wayne Gretzky graces the first cover
  - O-Pee-Chee Premier's rumoured limited print run and frenzy around the Jagr / Roenick / Fedorov RCs
- Counterfeit Patrick Roy and Brett Hull OPC cards begin to surface


#### 1991-92 More Sets, More Inserts
- Peak Junk Wax: 17 total sets, with more inserts and more production
- OPC releases one regular set and one Premier set
- Topps releases three sets: a regular set, Bowman, and the premium Stadium Club set
  - Regular set featured a full “Gold” parallel set, inserted one per pack
- Upper Deck: one English set, one French set, and an English / Czech set of World Junior players
- Pinnacle releases three Score sets (English, Canadian bilingual, American) and two Pinnacle sets 
 - Pro Set releases a regular, French and a premium Platinum set, plus Parkhurst in English and French
- Score, Bowman, Upper Deck Series 2, and OPC Premier also available as factory sets
- First McDonald's Upper Deck "All-Star" set released

#### 1992-93 Saturation, Pro Set Bankruptcy
- Sets reduced 13, but Pro Set doesn't survive
- Upper Deck releases one French and one English set
- OPC released a main and an over-produced Premier set
  - The “25th Anniversary” is the last-ever OPC set printed in Canada, with a unique design, still wrapped in wax paper, but no gum
- Pinnacle: four sets (two Score, two Pinnacle)
- Pro Set Series 1 of the main set, one Parkhurst including a parallel "Emerald" foil set
- Topps: main and Stadium Club
  - Pro Set Series 2 never released, company declares bankruptcy
- Fleer: new entrant with the premium Ultra set 
- Marvel buys Fleer, chasing the card boom

#### 1993-94 Consolidation Begins
- Fourteen total sets were released:
  - Two new sets from Leaf: Donruss & a Leaf main set
  - Fleer releases Ultra, and a “tall boy” PowerPlay set 
  - OPC and Topps only release premium sets:
    - Both release a Premier set 
    - Topps releases a Stadium Club set in the US
    - Stadium Club O-Pee-Chee set released for Canada
  - Upper Deck releases two sets: a main set and a Parkhurst set, after buying the rights from Pro Set
  - Pinnacle and sister brand Score had two sets each

#### 1994-95 More Sets, Smaller Sizes
- Twenty sets hit the market this year:
  - Upper Deck expands to seven sets across the Parkhurst, the ultra-premium SP, Be A Player, and Upper Deck brands:
  - Leaf: main set, Leaf Limited, and Donruss
  - Fleer: Ultra and Flair
  - Topps: Premier, Stadium Club, and Finest
  - Pinnacle: Select, Score, and a main Pinnacle set
  - OPC again had just a single Premier set, produced by Topps
 - NHL season shortened by the Owner’s lockout

#### 1995-96 Focus on "Scarcity", more Bankruptcies
- Market shift to smaller, premium sets, with a staggering 24 sets released:
  - Five Topps sets, including Bowman (165 cards), Super Skills (90), Finest (191), Stadium Club (225), and main set (385)
  - Four Fleer sets: Metal (200), SkyBox E-Motion (200), SkyBox Impact (250), and Ultra (400)
  - Four Leaf sets: main set (330), Limited (120), Donruss (390), and Donruss Elite (110)
  - Five Pinnacle sets, including a main set, two Score sets, Select Certified (144 cards, with a Gold parallel), and Zenith (150)
  - Five Upper Deck sets: main set, Be A Player, Collector’s Choice, two Parkhurst
- Marvel files for bankruptcy, taking the Fleer & SkyBox imprints with it

#### Long Term Impact
- The 2004-05 NHL lockout leads to a complete restructuring of NHL card licensing, with the NHL looking for credibility and stability: Upper Deck was granted the sole license from 2004 to 2009
- Upper Deck officially acquires Fleer / SkyBox and Parkhurst brands in 2005, and the O-Pee-Chee brand in 2006
- Upper Deck shares the license with Panini from 2010-11 to 2013-14, and regained exclusive status beginning with the 2014-15 season
- In 2021 it signed a long-term agreement with the NHL to become the sole physical hockey card manufacturer
